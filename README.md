# 🐧 Linux Learning Hub

> A hands-on learning hub for Linux administration — cheat sheets, labs, scripts, and troubleshooting guides for Ubuntu & CentOS.

![Linux](https://img.shields.io/badge/Linux-Ubuntu%20%7C%20CentOS-FCC624?style=flat-square&logo=linux&logoColor=black)
![License](https://img.shields.io/badge/License-MIT-blue?style=flat-square)
![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen?style=flat-square)

This repository is my structured path to mastering Linux — from essential commands to real-world operational skills. It is organized so that anyone can follow along, practice, and contribute.

## 📑 What's Inside

| Section | Description |
|---------|-------------|

---

## 🚀 How to Use This Repo

1. **Start with the [Roadmap](ROADMAP.md)** — follow the weekly plan.
2. **Read the relevant [Cheat Sheet](cheatsheets/)** for each week.
3. **Complete the [Lab](labs/)** for that topic.
4. **Explore the [Scripts](scripts/)** to see real-world usage.
5. **Check [Troubleshooting](troubleshooting.md)** when you hit errors.
