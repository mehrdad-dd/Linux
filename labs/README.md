# 🧪 Labs

Hands-on exercises to practice Linux skills. Each lab is self-contained and includes objectives, steps, and verification.

## Available Labs

| Lab | Topic | Difficulty | Time |
|-----|-------|------------|------|
| [01 - Basic Commands](01-basic-commands/) | Files, navigation, search | 🟢 Beginner | 20 min |
| [02 - User Management](02-user-management/) | Users, groups, permissions | 🟡 Intermediate | 30 min |
| [03 - Networking](03-networking/) | IP, ports, SSH | 🟡 Intermediate | 30 min |

## How to Use a Lab

1. Read the lab's `README.md`.
2. Follow the steps in a **safe environment** (VM, container, or WSL).
3. Run the verification commands at the end.
4. Compare your results with the `solution.md` file.
