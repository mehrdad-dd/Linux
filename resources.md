## 📌 How to Use These Resources

1. Start with **The Linux Command Line** (free PDF) — read one chapter per week.
2. Use **tldr** and **explainshell** daily while practicing.
3. Do labs on **Killercoda** or a local VM.
4. When stuck, search the **official docs** first, then ask in forums.
